# IncomeIQ – Income Category Prediction

A machine-learning project that predicts whether a person's annual income is **`>50K`** or **`<=50K`** from demographic, employment and financial attributes. It covers the full workflow: EDA, cleaning, a scikit-learn Random Forest pipeline with hyperparameter tuning, a FastAPI backend, a single-file web frontend and a Docker setup.

> **Educational project.** The dataset includes sensitive attributes such as race and sex. Predictions are not objective measures of anyone's worth, ability or real financial situation, and must not be used for decisions about people.

## Project structure

```
.
├── random_forest2.ipynb         # EDA, cleaning, training, tuning, evaluation, model export
├── adult_census_income.csv      # Adult Census Income dataset (needed to run the notebook)
├── main.py                      # FastAPI backend (loads model.pkl)
├── model.pkl                    # Saved tuned pipeline (generated by the notebook)
├── index.html                   # Frontend (HTML + CSS + vanilla JS, no build step)
├── requirements.txt             # Backend dependencies
├── Dockerfile
└── .dockerignore
```

## How it works

1. **Data** – Adult Census Income dataset. Duplicate rows are removed, and missing values stored as `?` (workclass, occupation, native-country) become an `Unknown` category.
2. **Features** – `fnlwgt` (a census sampling weight) and `education` (a duplicate of `education-num`) are dropped. `marital-status` and `relationship` are kept, since they are strong predictors.
3. **Pipeline** – `ColumnTransformer` (One-Hot Encoding for categorical columns, numeric columns passed through) followed by a `RandomForestClassifier` with `class_weight='balanced'`. Because preprocessing lives inside the pipeline, the API can send raw columns.
4. **Evaluation** – Stratified train/test split, a majority-class baseline (always predicting `<=50K` is already about 76% accurate, so accuracy alone is misleading), and accuracy, F1 and ROC-AUC.
5. **Tuning** – `RandomizedSearchCV` with `StratifiedKFold`, scored on F1.
6. **Serving** – the tuned pipeline is saved as `model.pkl` and loaded by FastAPI.

## Run locally

Requires Python 3.12+ (other recent versions should work).

```bash
pip install -r requirements.txt   # use the same scikit-learn version the model was trained with
uvicorn main:app --reload
```

- API docs (Swagger UI): http://127.0.0.1:8000/docs
- Frontend: open `index.html` in your browser. The backend address is the `API_BASE` constant at the top of its script.

To regenerate the model, run all cells of `random_forest2.ipynb` with `adult_census_income.csv` in the same folder. The last cell writes `model.pkl`.

## Run with Docker

```bash
docker build -t incomeiq-api .
docker run -d --name incomeiq -p 8000:8000 incomeiq-api
```

`model.pkl` must exist in the project folder before building. Pin `scikit-learn` in `requirements.txt` to the version used for training, because pickled models can break across versions.

## API

### `GET /`
Health check. Returns `{"message": "homepage"}`.

### `POST /predict`

Request body (hyphenated keys are required):

```json
{
  "workclass": "Private",
  "marital-status": "Never-married",
  "occupation": "Prof-specialty",
  "relationship": "Not-in-family",
  "race": "White",
  "sex": "Male",
  "native-country": "United-States",
  "age": 30,
  "education-num": 13,
  "capital-gain": 0,
  "capital-loss": 0,
  "hours-per-week": 40
}
```

Response:

```json
{
  "prediction": ">50K",
  "probability_over_50K": 0.8234
}
```

`probability_over_50K` is the model's estimated class probability, not a guarantee.

| Field | Rule |
|---|---|
| `age` | integer, 17–100 |
| `education-num` | integer, 1–16 (census scale, e.g. 13 = bachelor's) |
| `capital-gain`, `capital-loss` | number ≥ 0 (default 0) |
| `hours-per-week` | number > 0 and ≤ 99 |
| `workclass`, `occupation`, `native-country` | must be a value seen in training; default `Unknown` |
| `marital-status`, `relationship`, `race`, `sex` | required, must be a value seen in training |

Invalid input returns HTTP **422** with details. If you call the API from a browser, the backend needs `CORSMiddleware` enabled (see `main.py`).

## Tech stack

Python, pandas, scikit-learn, FastAPI, Pydantic, Uvicorn, Docker, vanilla HTML/CSS/JavaScript.

## Limitations

- Trained on a historical US census sample, so it will not reflect current or non-US income patterns.
- The model only sees the listed attributes and returns no per-feature explanations for individual predictions.
- Income is predicted as two broad classes, not an amount.

## Dataset

Adult Census Income dataset (UCI Machine Learning Repository). Check the source's terms before redistributing the data.
