About the model

IncomeIQ is a classifier trained on the Adult Census Income dataset. It sorts a profile into <=50K or >50K.

🌲

Random Forest Classifier

Many decision trees vote on the income category. Class weights balance the smaller >50K group.

🧹

Data cleaning

Duplicate rows are removed. Missing values stored as “?” become an “Unknown” category.

🧩

One pipeline

One-Hot Encoding and ColumnTransformer sit inside a scikit-learn Pipeline, so the API sends raw columns.

⚖️

Fair comparison

A stratified train-test split keeps class ratios equal, and a majority-class baseline gives a reference point.

🎛️

Tuning

RandomizedSearchCV with StratifiedKFold cross-validation searches forest settings, scored on F1.

📊

Evaluation

Accuracy, F1-score and ROC-AUC are checked, plus a feature importance review.
